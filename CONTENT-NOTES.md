# Question-bank review — 14 October 2026

This edition contains 2,000 questions, exactly 100 in each of 20 categories. Each has three distinct choices: one intended answer and two alternatives. Wording was authored for this app rather than copied from an existing quiz bank.

## Checks completed

- Factual and wording review, including targeted web checks and topic-level reference reads.
- Removed exact duplicates and identified cross-category repetitions of the same facts.
- Corrected ambiguous alternatives, overly broad claims and questions that gave away their answer.
- Checked category counts, unique stable IDs, non-empty fields and three distinct choices automatically.
- Included a reference URL for every question, shown after answer reveal.

Sources include NASA, USGS, San Diego Zoo, official programme and game sites, reference encyclopaedias, publishers, education sites and sport organisations. Source links may cover a broader topic rather than the exact sentence in a question.

## Verification limits

This is a reviewed question bank, not a certified error-free database. Web verification was topic-based and targeted; a separate independent web verification of every one of the 2,000 answers has not been completed. Some reference pages were inaccessible during checking. A reference link alone does not mean its full contents were successfully read. In particular, the Famous people, Books and literature, Everyday objects and Mixed fun facts groups received factual/wording review and selected web checks, not a completed per-question online audit.

Difficulty is intended to be easy with the choices supplied; some specialist questions will feel harder depending on the team. Stable facts were preferred, although rules, brands and web links can change. Use Hide / flag if a question needs review. Flags and notes stay in your browser and are included in backups; they are not submitted anywhere.

## App verification

Automated checks passed for question counts, exact duplicates, choice uniqueness, category and mixed-round exclusions, randomised choice integrity, skipping and undoing, round save/reload, backup merging and invalid imports, and running out of unused questions. JavaScript syntax checks passed. No browser rendering or actual iPhone test was available in the build environment.
